## benchmark_methodology
Each trial runs one redis-benchmark invocation of an EVAL script.
One request pushes five elements and reads those five back:
redis.call('LPUSH', KEYS[1], 'v1', 'v2', 'v3', 'v4', 'v5'); return redis.call('LRANGE', KEYS[1], 0, 4)
Requests per trial therefore equals commands per trial.
Lua interpreter allocations are part of this measurement.
